# Hermann

Software engineering student, finishing my last semester at Tec de Monterrey (Monterrey, Mexico). I mostly write TypeScript and Python, and I also like the lower-level stuff — audio, DSP, C, and C++ when the project calls for it.

I'd rather build things that people actually use than talk about what I can build. That's meant a real store's online shop and POS sync, a reservations system an office runs on, an original wavetable synth as a VST3, a 3DS synth in C, and a channel-surfing web game. A few of them are below.

## Day to day

TypeScript and React/Next.js up front, Node/Express/FastAPI behind it, PostgreSQL and Supabase for data. I've shipped a few AI features (RAG, Gemini/Groq/OpenAI, pose estimation) and I keep C++/JUCE and Raspberry Pi projects around for fun.
